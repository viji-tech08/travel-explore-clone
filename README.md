# Travel Explorer

Travel Explorer is a responsive travel website created using **HTML and CSS**.  
It is designed to help users explore destinations, travel experiences, hotels, restaurants, and popular places.

## Features

- Responsive navigation bar
- Travel search section
- Hotel, restaurant, flights and things-to-do tabs
- Travel adventure banner
- Beautiful travel experience cards
- Popular destinations section
- Things-to-do section with ratings
- Restaurant section
- Responsive design for desktop, tablet and mobile devices
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## Responsive Design

The website is responsive and works across different screen sizes:

- Desktop
- Mobile
- Tablet
